# Astroworld: Cactus Jack Concert — Fabric 1.20.1

Креативный предмет **Cactus Jack Mic** (вкладка «Инструменты и утилиты»).
ПКМ с ним запускает 80-секундный концерт: полночь, неоновое небо, гигантский аватар,
кольца частиц, молнии без урона, левитация на бит-дропах (15/30/45/60/75 с), титры «IT'S LIT!» и т.д.

## Способ А (проще всего, ничего не ставить): сборка в облаке GitHub
1. Зарегистрируйтесь на github.com → New repository → загрузите ВСЮ эту папку (Add file → Upload files).
2. Вкладка **Actions** → «Build mod» → дождаться зелёной галочки (2–5 минут).
3. Откройте завершённый запуск → внизу **Artifacts** → скачайте `astroworld-mod-jar` → внутри `astroworld-1.0.0.jar`.

## Способ Б: сборка на своём компьютере
1. Установите **JDK 17** (например, Temurin 17) и **Gradle 8.5** (gradle.org/releases).
2. В папке проекта выполните: `gradle build`
3. Готовый мод: `build/libs/astroworld-1.0.0.jar` (файл `...-sources.jar` не нужен).

## Установка
- Minecraft Java **1.20.1**, Fabric Loader **0.15.x**, **Fabric API 0.92.2+1.20.1**.
- Положите `astroworld-1.0.0.jar` и Fabric API в папку `mods`.
- Мод нужен и на клиенте, и на сервере.

## Как играть
Креатив → вкладка «Инструменты и утилиты» → **Cactus Jack Mic** → ПКМ.
Лучше стоять на открытой местности. Музыка играет у всех игроков в радиусе 128 блоков.

## Своя музыка (SICKO MODE)
В моде лежит **заглушка** `sicko_mode.ogg` (простой синтезированный бит 160 BPM, 80 с), а не сам трек —
оригинальную песню (авторские права) положить внутрь я не могу.
Чтобы поставить свой файл: замените
`src/main/resources/assets/astroworld/sounds/sicko_mode.ogg`
и пересоберите. Требования: формат **OGG Vorbis**, имя ровно `sicko_mode.ogg`, строчными буквами.
Конвертация: `ffmpeg -i song.mp3 -c:a libvorbis -q:a 4 sicko_mode.ogg`.
Концерт идёт 80 с — обрежьте аудио до 80 секунд (или подгоните тайминги, см. ниже).

## Настройка
- Длительность: `ConcertManager.DURATION_TICKS` (20 тиков = 1 с; 1200–1800 = 60–90 с).
- Моменты бит-дропов: `ConcertSession.DROPS`; надписи: метод `script()` в `ConcertSession`.

## Модель и HD-текстура аватара (v1.1)
- Скелет: те же head/hat/body/right_arm/left_arm/right_leg/left_leg с ванильными pivot-точками. Всё новое (брейды, худи-капюшон,
  жилет, цепи, браслеты/часы, кроссовки) — дочерние части, поэтому анимации не ломаются.
- Текстура: `cactus_avatar.png` 512x512 (логическая сетка 128x128, 4 px на единицу модели).
- Слои как в скине игрока: hat = волосы, jacket = худи, *_sleeve = рукава, *_pants = штаны.
- Менять дизайн: правьте `tools/generate_avatar.py` (нужны `pip install pillow numpy`) и запустите
  `python3 tools/generate_avatar.py` — он перезапишет и PNG, и `AvatarGeometry.java` (UV всегда совпадают).
  Для 256x256 поставьте `SCALE = 2`, для 1024x1024 — `SCALE = 8`.
- Модель рисуется полностью яркой и с буфером глубины (многослойная одежда не просвечивает).
